# Week 02 – Penetration Testing: Footprinting & Network Scanning

## Project Overview

This repository documents my Week 2 practical cybersecurity activities completed as part of the Networkwalks Cybersecurity Programme.

The project focuses on two important penetration testing phases: Reconnaissance and Footprinting, followed by Network Scanning and Discovery.

The practical exercises involved using Kali Linux security tools to gather information about a target domain and identify active devices on a local network.

## Objectives

- Perform reconnaissance and information gathering.
- Identify publicly available domain information.
- Analyse DNS records and web technologies.
- Identify web application firewall information.
- Perform network discovery and scanning.
- Identify active hosts on a local network.
- Understand potential security risks and document findings.

## Tools and Technologies

- Kali Linux
- WHOIS
- WhatWeb
- Nslookup
- Curl
- Wafw00f
- DNSRecon
- Zenmap
- Nmap
- Oracle VirtualBox

## Practical Activities

### Phase 1: Reconnaissance and Footprinting

Used multiple Kali Linux tools to gather information about the target domain, including domain registration details, DNS information, web technologies, HTTP response headers and firewall identification.

### Phase 2: Network Scanning and Discovery

Used Zenmap and Nmap to perform local network discovery, identify active hosts, analyse network information and generate a network topology.

## Key Learning Outcomes

- Gained practical experience with reconnaissance techniques.
- Improved understanding of DNS enumeration.
- Learned how to identify web technologies.
- Developed practical network scanning skills.
- Gained experience analysing network discovery results.
- Improved cybersecurity documentation and reporting skills.
